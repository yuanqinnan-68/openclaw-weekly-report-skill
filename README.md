# OpenClaw 周报总结 Skill

把飞书周报原始任务整理为适合邮件阅读的项目周报，并保留当前线上已经确认的业务规则。

核心流程：

`读取飞书原文 → 按项目整理 → 大模型提炼 → 结构校验 → 状态排序 → 生成邮件`

仓库内容：

- `SKILL.md`：智能体处理周报时必须遵守的规则。
- `references/report-contract.md`：字段、排序、亮点和完整性约束。
- `references/integration.md`：OpenClaw、飞书、模型和邮件发送的集成边界。
- `implementation/`：当前线上核心整理服务、HTML 渲染器和邮件模板的脱敏快照。

## 安全说明

本仓库不保存生产环境的邮箱授权码、飞书密钥、模型 API Key、数据库密码、服务器地址或内部文档 Token。所有敏感配置必须通过环境变量或部署平台的密钥管理功能提供。

## 后续优化建议

修改摘要提示词或排序逻辑后，至少验证：任务条数不变、空字段仍为空、亮点最多 5 条、每个项目内状态顺序正确、HTML 中不存在半句截断。不要用真实收件人做自动化测试。
